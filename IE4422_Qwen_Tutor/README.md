# IE4422 — Qwen2.5-VL Science Tutor Starter

**Shared repository workflow:** follow [the integration guide](../docs/QWEN_INTEGRATION.md) to use the team's prepared ScienceQA questions with `run_scienceqa_tutor.py`. The commands below are the original standalone diagram demo. Use the separate Qwen environment described in that guide; the team's data dependency lock remains separate.

A **starter prototype**, not a validated diagnostic or research evaluation system. It loads **one** Qwen2.5-VL-3B-Instruct model in 4-bit and reuses it for (1) visual evidence extraction, (2) tentative misconception diagnosis, and (3) targeted hints. Outputs may contain errors or reveal answers: **review them before using them with students**.

## Recommended hardware
Windows laptop with NVIDIA RTX 4060 (8 GB VRAM), 16 GB RAM; NVIDIA driver; Python 3.11. Memory usage varies with image size and prompts. Model download requires internet and several GB free on disk.

## 1. Setup (PowerShell)

```powershell
cd IE4422_Qwen_Tutor
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Install NVIDIA CUDA-enabled PyTorch from the official selector: https://pytorch.org/get-started/locally/ . Then:

```powershell
pip install -r requirements.txt
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'No GPU detected')"
```

CUDA must print `True`. If PowerShell blocks activation, use `cmd.exe` and `.venv\Scripts\activate.bat` instead.

## 2. Test diagram reading

Place **your own science diagram** at `images/science_diagram.png`. We deliberately do not include a fake diagram. Then:

```powershell
python test_qwen.py --image images/science_diagram.png
```

First run downloads model weights from Hugging Face and caches them. If already downloaded, use `--model-path "C:\path\to\model"` pointing to the full model directory.

## 3. Run the whole pipeline

```powershell
python run_tutor.py --image images/science_diagram.png --question "What does the arrow represent in this diagram?" --answer "Movement" --explanation "I think the arrow shows where the animal walks" --hint-level 1
```

The result prints to the terminal and saves to `tutor_result.json`. Your examples should use a real diagram, actual matching question, and student response.

## What files do

- `qwen_engine.py`: loads 4-bit Qwen and accepts image-plus-text prompts.
- `test_qwen.py`: tests visual understanding of one diagram.
- `tutor_pipeline.py`: three prompt-driven stages and illustrative misconception classes.
- `run_tutor.py`: command-line demo; saves outputs to JSON.
- `requirements.txt`: Python dependencies excluding PyTorch (install CUDA build separately).

## Scientific caveats

- The misconception categories in this starter are **illustrative**, not a research-validated inventory. Ground/revise with suitable literature and educator input.
- Incorrect multiple-choice answers alone do not prove a specific misconception. This code explicitly allows uncertain diagnoses.
- The evidence and diagnosis are generated by the model, **not independent verified annotations**.
- Hints are not guaranteed to withhold answers; this starter **does not implement an independent answer-disclosure safeguard**.
- For evaluation, add fixed splits, baseline B/C/D/F implementations, latency logging, manual rubric, and blinded ratings. These are not included in this starter.
- This starter does not fine-tune the model.

## Troubleshooting

- **CUDA not available**: install the CUDA-enabled PyTorch wheel; update NVIDIA drivers.
- **CUDA out of memory**: close GPU applications, use smaller readable images, keep runs sequential. Do not reduce resolution so far that arrows/labels are unreadable.
- **bitsandbytes errors**: update bitsandbytes/transformers and verify installed CUDA PyTorch on supported Windows builds.
- **Model download fails**: check internet, model directory and free disk space.
- **JSON not valid**: model generation is not constrained to valid JSON; improve prompting or add parser/validation in later iterations.
